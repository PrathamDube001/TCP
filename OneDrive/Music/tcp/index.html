Reliability

Every byte has a sequence number. The receiver sends ACKs, and the sender retransmits anything that isn’t acknowledged in time.

Ordering

Segments can arrive out of order. TCP uses sequence numbers to put the bytes back in order before the application sees them.

Flow control

Each ACK carries a window size: how much more data the receiver can hold. The sender never sends more than that.

Congestion control

The sender starts slowly and speeds up while ACKs return, then backs off when packets are lost, so it doesn’t overload the network.

Sliding window and congestion window

The sender may have at most cwnd segments in flight at once. Every acknowledgment slides the window forward. Step through round trips (RTTs) and trigger a loss to see slow start, congestion avoidance and the back-off.

Teal = acknowledged, purple = in flight, empty = not yet sent. A triple duplicate ACK halves cwnd; a timeout drops it back to 1 segment. The real limit is the smaller of cwnd and the receiver’s advertised window.

    TCP vs UDP

    Both run on top of IP. They make opposite trade-offs between reliability and speed.

    TCPUDP
    ConnectionConnection-oriented: a handshake comes firstConnectionless: just send
    ReliabilityLost data is retransmittedNo retransmission; lost datagrams stay lost
    OrderingBytes are delivered in orderDatagrams can arrive in any order
    Flow and congestion controlYesNone
    Data modelContinuous byte streamSeparate messages (datagrams)
    Header size20 to 60 bytes8 bytes
    SpeedSlower: handshake, ACKs, waiting for resendsFaster, lower latency
    Typical usesWeb (HTTP/HTTPS), email, file transfer, SSHDNS, video calls, online games, live streaming

    Choose TCP when every byte must arrive correctly. Choose UDP when speed matters more than perfection, or when the application handles loss itself. HTTP/3 is built on QUIC, which runs over UDP and adds its own reliability.

    Sequence numbers here are small on purpose. Real connections start at a random 32-bit number and count bytes, not segments.
